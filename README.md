# Gen-bot-dc

Discord bot + web dashboard project built with TypeScript, React, Express, Discord.js, and Drizzle ORM.

## Overview

Gen-bot-dc combines a Discord bot with a browser dashboard for server configuration and management. The repository is structured as a full-stack application rather than a standalone Discord bot.

## Stack

- TypeScript
- Node.js
- Discord.js
- Express
- React
- Tailwind CSS
- Drizzle ORM

## Development

```bash
npm install
npm start
```

Environment variables and database configuration should be supplied through a local `.env` file. Never commit real Discord tokens, database credentials, or other secrets.

## Repository

The project contains bot logic, API/dashboard routes, database schema, React UI components, and supporting configuration.

## Status

Active development / experimental full-stack project.
